🚀 Quick Start Guide

Step 1: Capture thermal images with your FLIR camera
  • Save as JPEG format with embedded thermal data
  • Take 1-8 images per building survey area
  • Include reference markers or context if possible
Step 2: Upload images via the home page
  • Click "Choose Files" and select your thermal images
  • Maximum 8 images per batch (recommended: 6-8 for best results)
  • Only .jpg and .jpeg formats accepted
Step 3: Processing happens automatically
  • Temperature data extraction from FLIR metadata
  • Dual-method hot spot detection (relative + absolute)
  • Image annotation with color-coded markers
  • HTML report generation with building survey insights
Step 4: Review your results
  • View batch summary on home page
  • Download temperature CSV files
  • Read HTML thermal analysis reports
  • Check labeled images with hot spot markers

📖 Interpreting Your Thermal Reports

Hot Spot Severity Levels

Severity Color Meaning Action Required
CRITICAL 🔴 Red Temperature >3 standard deviations above mean Immediate investigation required - Major thermal issue
HIGH 🟠 Orange-Red Temperature 2-3 std devs above mean Schedule detailed inspection within 2 weeks
MEDIUM 🟧 Orange Temperature 1-2 std devs above mean Monitor area, investigate during routine maintenance
LOW 🟡 Yellow Temperature <1 std dev above mean Document for reference, likely normal variation

Common Thermal Patterns & Causes

Large Area Hot Spots (>100 pixels)
  • Critical: Major insulation failure, missing insulation, or active heat source
  • High/Medium: Thermal bridging through studs, insulation compression
Localized Hot Spots (<50 pixels)
  • Critical: Electrical issue, severe air leak, pipe penetration
  • High/Medium: Air infiltration point, small gap, fastener thermal bridge
Linear Hot Spots
  • Wall studs or ceiling joists (thermal bridging)
  • Air leaks along framing joints
  • Window/door frame issues

Building Survey Context

Location Likely Issues Investigation Steps
Walls Stud thermal bridging, cavity insulation gaps, air leaks Check for stud spacing patterns, verify insulation fill, blower door test
Ceilings Missing attic insulation, compressed insulation, recessed lights Inspect attic above detected areas, check insulation depth/quality
Windows/Doors Failed weather sealing, frame thermal bridging, air leaks Verify weather stripping, check frame installation, test for drafts
Corners 3D thermal bridging, insulation installation challenges Verify corner insulation technique, check for compression

🔄 Complete Workflow

1. Image Capture Best Practices

  • Timing: Capture images during maximum temperature differential (dawn/dusk in winter, midday in summer)
  • Distance: Maintain consistent distance from target surface (3-10 feet typical)
  • Angle: Perpendicular to surface when possible, avoid reflections
  • Reference: Include visible context markers or take paired visible-light photos
  • Settings: Set emissivity correctly for material being surveyed (0.9 for most building materials)

2. System Processing Pipeline

  1. Temperature Extraction: FLIR metadata parsed to recover raw temperature data
  2. Statistical Analysis: Mean, median, std deviation, min/max calculated
  3. Primary Detection (Relative): Local maxima found using 9x9 pixel neighborhood
  4. Backup Detection (Absolute): Fixed temperature threshold applied (default 30°C)
  5. Region Analysis: Connected components identified, noise filtered out
  6. Severity Classification: Each hot spot rated based on statistical deviation
  7. Report Generation: HTML narrative created with building survey context
  8. Image Annotation: Labeled JPEGs created with colored markers
